# Personal Expense Tracker

A responsive React-based personal finance tracker for recording income and expenses, filtering transactions, visualizing spending habits, and persisting data in LocalStorage.

## Features
- Add, edit and delete transactions
- Income and expense transaction types
- Categories: Food, Travel, Bills, Shopping, Health, Education, Entertainment and Other
- Search and category filtering
- Total Income, Total Expenses and Current Balance cards
- Pie chart for category-wise spending
- Bar chart for recent monthly income vs expenses
- React Context API + Hooks for client-side state management
- LocalStorage persistence
- Responsive mobile and desktop UI

## Tech Stack
- React.js
- Context API
- React Hooks: useState, useEffect, useContext, useMemo
- Recharts
- CSS responsive layout
- LocalStorage
- Vite

## Run the project
1. Install Node.js.
2. Open this project folder in VS Code/terminal.
3. Run:
   npm install
4. Start:
   npm run dev
5. Open the local Vite URL shown in the terminal.

## Build
npm run build
